# Trace Research Paper Studio

When the user asks to analyze a research paper or create a Trace project, activate the `trace-paper-studio` skill. Use Gemini CLI's current model as the reasoning engine; do not ask for a separate LLM API key. Keep every published statement linked to paper evidence, validate the generated `.trace.json`, then run the bundled delivery command so the completed local Trace website opens automatically. Always preserve and report the importable JSON path.
